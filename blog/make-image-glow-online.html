How to make an image glow online

PUBLISHED 3 AUGUST 2026 · BY NIMROD YARKONI

There are two ways to make an image glow online, and they produce completely different results. A glow filter paints a halo effect into the pixels: it shows on every screen, survives screenshots, and looks like editing. An HDR glow embeds a color profile that makes the bright parts of the image emit real extra light on HDR screens: no halo, no visible editing, the image simply looks backlit. The second kind is what makes logos glow in the LinkedIn feed, and Superwhite does it in your browser.

Which kind of glow do you want?

If you want a decorative halo around an object, any glow filter will do: Canva has one, Photoshop has Outer Glow, CapCut and most photo apps have a bloom effect. Those are pixel effects. They are visible everywhere, including in print, and they read as a design choice.

If you want the image itself to be brighter than the screen around it, no filter can do that, because filters can only rearrange the brightness the image already has. Real glow needs the display's HDR headroom: the reserve brightness above normal white that only an HDR color profile can unlock. That is a property of the file's encoding, not of its pixels.

Can AI make an image glow?

Not this kind of glow. Image generators like Midjourney, DALL-E and Gemini can draw a glow effect into the pixels, which is the filter kind. They output standard SDR files, so nothing they produce renders brighter than screen white. The HDR glow lives in a Rec.2100 PQ color profile embedded in the JPEG, which generators and editors do not write. Generate your image with AI if you like, then run the file through Superwhite to add the real glow.

What about CSS glow effects?

CSS can add glow-like shadows and even trigger real HDR brightness on your own website with wide-gamut colors, but none of it travels: the moment the visual is uploaded to a platform as an image, the CSS is gone. For a glow that survives inside a social feed, the effect has to be inside the image file itself.

Frequently asked questions

How do I make an image glow online?

What is the difference between a glow filter and an HDR glow?

A glow filter paints a halo into the pixels and shows on every screen, like any edit. An HDR glow changes the file's color encoding so bright areas render above normal screen white on HDR displays, which looks like real emitted light and cannot be reproduced by editing pixels.

Can Canva or Photoshop make an image glow brighter than white?

No. Editors can only rearrange the brightness an image already has, up to normal screen white. Rendering above screen white requires an HDR color profile in the file, which standard editor exports do not include.

Can AI image generators make a glowing image?

They can draw a glow effect, but their output is standard SDR, so it never renders brighter than screen white. Generate the image with AI, then add the real HDR glow with a tool like Superwhite.

Why does my glowing image look normal on some screens?

The HDR glow only renders on HDR-capable displays with HDR enabled and battery saver off. On other screens the same file looks like a normal image with slightly dimmer whites.

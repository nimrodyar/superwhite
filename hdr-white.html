What HDR white actually is

An ordinary image stores white as the maximum code value, 255, and leaves it to the display to decide how bright that is. Actual interface-white brightness varies with the system and display settings; 203 nits is a reference used in this tool's encoding, not a measurement of every screen. An HDR white image stores the same pixels with the PQ transfer function from SMPTE ST 2084, which maps code values to absolute luminance up to 10,000 nits, and tags the file with a Rec.2100 PQ colour profile so the browser or OS knows to read it that way. An HDR display then spends its extra headroom on those pixels. The visible result depends on the display's available headroom; the encoded luminance target does not guarantee a measured brightness.

Nothing is added to the artwork. No halo, no blur, no bright pixels painted around the shape. The white you already have is simply allowed to be brighter than the white of everything else on screen.

How to make an HDR white image

  1. Start with real white. The effect keys on luminance. Pure white and near-white pixels glow; mid-greys and colours stay where they are. White marks on dark or saturated backgrounds look best.
  2. Drop it into Superwhite. Choose Subtle, Standard or Max. Standard targets 1,000 nits with the glow starting at 70 percent white; the advanced controls expose both numbers.
  3. Download the HDR JPEG. Superwhite flattens near-white JPEG noise before encoding, dithers in PQ code space so smooth areas do not band, and writes 4:4:4 chroma at quality 97 so coloured edges stay crisp against the glowing white.
  4. Serve the file as is. Any step that re-saves it through an SDR editor or strips metadata removes the effect.

Frequently asked questions

What is HDR white?

HDR white is white encoded as an absolute luminance above the display's interface white, whose actual brightness varies by screen and settings. An HDR display spends its extra headroom on those pixels, so they render visibly brighter than the white of the page or app around them. On SDR displays there is no extra HDR brightness; colour and tone mapping can vary.

Why does the HDR white swatch look the same as the normal white on my screen?

Your display or browser is not giving the page any luminance headroom. Common causes: an SDR monitor, HDR switched off in the operating system, low battery or low power mode on a laptop or phone, or a browser that does not support the CSS rec2100-pq colour space. Recent MacBook Pro, iPhone, iPad Pro and many OLED Android phones show it in Chrome and Safari.

How do I make an HDR white image?

Open Superwhite, drop a PNG or JPEG, choose a glow strength and download. The white and near-white pixels are re-encoded with the PQ transfer function and the file is tagged with a Rec.2100 PQ ICC profile. Everything runs in the browser and nothing is uploaded.

Where does an HDR white image actually glow?

On surfaces that serve your file unchanged: your own website, HTML email, direct downloads, slide decks that embed the original file, and most places that preserve the ICC profile. LinkedIn stripped the profile in September 2026 so it no longer glows there. Instagram and Facebook need a gain map JPEG instead.

Is an HDR white image the same as a brighter or bloomed white?

No. A brightness or bloom filter changes pixel values but they are still capped at the display's SDR white. HDR white changes how the pixel values are interpreted, so the display can render them above that cap. Nothing is painted around the shape.

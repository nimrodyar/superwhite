How to put an HDR image on your website

By Nimrod Yarkoni · Updated 17 November 2026

An HDR image can make the white parts of a logo, wordmark or small illustration brighter than the page around it on a compatible HDR display. Superwhite creates a JPEG for that effect. The key to publishing it is simple: serve the exported file unchanged.

Start with one small, useful highlight

Use a logo, a product highlight or a short hero graphic. Keep important text as real HTML, with accessible contrast, and give the image useful alternative text. An entire page of intense white is uncomfortable; a restrained accent is a better starting point. Your design should still make sense when no glow is visible.

Export the right size

  1. Open Superwhite and load your original PNG or JPEG.
  2. Try Subtle or Standard, then check the result on an HDR-capable screen.
  3. Download the HDR JPEG. Simple covers exports up to 400px; Creator covers up to 1400px for larger artwork.
  4. Keep the original SDR image too, so you have a fallback and a source for future edits.

JPEG does not preserve transparency. Prepare the background you actually want behind the artwork before exporting. For a small logo, set its displayed dimensions deliberately rather than stretching a 400px export across a large hero.

Embed the original JPEG

<img src="/images/my-logo-hdr.jpg"
     alt="Your company name" width="400" height="240"
     style="max-width:100%;height:auto">

Upload the file to a static asset location that serves its original bytes. The path above is an example: replace it with your own file. Width and height reserve space and reduce layout shifts. Ordinary CSS resizing does not rewrite the file, but an image-processing service can.

Watch your CMS, CDN and image optimiser

  • Use an original-file URL. Some media libraries serve a resized derivative by default.
  • Bypass automatic format conversion for this asset. An optimiser that creates WebP, AVIF or a new JPEG may drop the profile or change how the pixels are interpreted. Those formats can support HDR in other workflows; conversion alone does not preserve this one.
  • Check the delivered file. Download the image from the deployed page and compare it with your export. A successful upload does not prove that the final CDN response is unchanged.
  • Test after deployment. A local preview can work while the production image pipeline removes the effect.

Plan for screens that do not show the glow

Superwhite's PQ-profile workflow is intended for compatible Chrome, Edge and Safari combinations on HDR displays. Treat Firefox and any unverified browser or operating-system combination as needing an SDR check. Brightness, available headroom and power-saving settings can all change the result.

A PQ JPEG does not carry a separate SDR rendition. If your brand colours must match precisely everywhere, provide an SDR version and test your selection logic. A browser reporting HDR capability is not proof that every HDR file format will render as intended.

When the exported image looks flat

First check the display with the free HDR test. Then open the exported JPEG directly and compare it with the version delivered by your website. If only the deployed version loses the effect, investigate the image pipeline before increasing the glow setting.

Frequently asked questions

Can I use an HDR JPEG in a normal img tag?

Yes. A normal img tag can serve the exported JPEG. The viewer still needs a compatible browser, operating system and HDR display, and the image service must preserve the file.

Will WebP or AVIF conversion preserve the glow?

Do not assume it will. These formats have their own HDR capabilities, but a normal optimisation pipeline may strip the profile or tone-map the image. Test the delivered file or serve the original export.

Will the HDR logo look identical on every screen?

No. Available brightness and colour handling vary. Keep an SDR original and test fallback behaviour when consistent appearance matters.

Does this make LinkedIn logos glow?

No. This guide is for a website you control. Superwhite records LinkedIn removing the profile since September 2026.
